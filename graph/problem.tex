% Motivation for transfer learning 

Developing task-specific scripts for each robot is a time-consuming.
At the same time, driving a robot using deep-learning model is not consideed safe. Since deep-learning models are black-boxes, it is hard to explain the decision-making process.
Also, training such a model for each robot requires huge amount of data specific to the robot and the task.
